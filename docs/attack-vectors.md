# SourceGate Attack Vectors

This document lists package-registry attack vectors that are in scope for SourceGate. Each example is an incident or attack pattern that SourceGate should be able to block or alert on through metadata inspection, archive inspection, lifecycle-script detection, suspicious string/path detection, or policy rules.

| Attack vector | Description | Example | Reference |
| --- | --- | --- | --- |
| Malicious package publication | An attacker publishes a package whose purpose is credential theft, malware delivery, persistence, or unauthorized command execution. SourceGate can alert on a new or low-reputation package with suspicious files, scripts, network indicators, or credential-access strings. | Malicious PyPI packages have repeatedly shipped credential stealers and cryptominers through public package names that appear useful or legitimate. | [Sonatype PyPI cryptomining malware](https://www.sonatype.com/blog/sonatype-catches-new-pypi-cryptomining-malware-via-automated-detection), [Practical Automated Detection of Malicious npm Packages](https://arxiv.org/abs/2202.13953) |
| Typosquatting | An attacker publishes a package with a name visually or phonetically close to a legitimate package. SourceGate can compare requested package names against popular packages and warn or block when similarity is high. | The npm `hacktask` campaign published 39 packages with names similar to popular npm packages and used them to steal developer credentials. | [The Register: npm typosquatting campaign](https://www.theregister.com/2017/08/02/typosquatting_npm/), [Detecting Active and Stealthy Typosquatting Threats](https://arxiv.org/abs/2502.20528) |
| Combosquatting | An attacker adds words, prefixes, suffixes, scopes, or brand terms around a trusted package or organization name to create a plausible fake. SourceGate can detect suspicious name similarity, brand impersonation, and low package age. | The fake npm package `tanstack` impersonated the legitimate `@tanstack/*` ecosystem and attempted to exfiltrate environment variables. | [Socket: TanStack brandsquat compromise](https://socket.dev/blog/tanstack-brandsquat-compromise), [Survey on npm and PyPI registry threats](https://arxiv.org/abs/2108.09576) |
| Dependency confusion | An attacker publishes a public package with the same name as an internal dependency, often relying on version or registry-resolution behavior to make the public package win. SourceGate can enforce private namespace policy and block public resolution of internal package names. | Alex Birsan demonstrated dependency confusion against companies including Apple, Microsoft, Tesla, and others by publishing packages that matched internal dependency names. | [Ars Technica: dependency confusion](https://arstechnica.com/information-technology/2021/02/supply-chain-attack-that-fooled-apple-and-microsoft-is-attracting-copycats/), [Sophos: dependency confusion overview](https://news.sophos.com/en-us/2021/02/16/how-one-man-silently-infiltrated-dozens-of-high-tech-networks/) |
| Maintainer compromise | An attacker compromises a legitimate maintainer account and publishes malicious versions under an otherwise trusted package name. SourceGate can alert on sudden new versions with lifecycle hooks, obfuscated payloads, binaries, or credential-access behavior. | The npm package `ua-parser-js` was hijacked and malicious versions installed credential stealers and cryptominers. | [CISA: ua-parser-js alert](https://www.cisa.gov/news-events/alerts/2021/10/22/malware-discovered-popular-npm-package-ua-parser-js), [CERT-EU: ua-parser-js advisory](https://cert.europa.eu/publications/security-advisories/2021-057/) |
| Ownership transfer abuse | A legitimate package is transferred to a new maintainer who later publishes a malicious dependency or version. SourceGate can warn on recent maintainer changes and new transitive dependencies in high-impact packages. | The `event-stream` incident involved a trusted package adding the malicious `flatmap-stream` dependency after maintainer control changed. | [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident), [Snyk: flatmap-stream malware](https://security.snyk.io/vuln/SNYK-JS-FLATMAPSTREAM-72637) |
| Dormant package takeover | A package that has been inactive for a long time suddenly publishes a new release containing suspicious behavior. SourceGate can compare publish history against package age and flag long-dormant release anomalies. | `event-stream` had been broadly trusted before the malicious dependency chain was introduced, making release-history and maintainer-change signals relevant. | [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident), [GitLab Advisory Database: event-stream](https://advisories.gitlab.com/pkg/npm/event-stream/) |
| Lifecycle script abuse | Attackers use package-manager lifecycle hooks such as `preinstall`, `install`, `postinstall`, `prepare`, or Python build hooks to execute code during installation. SourceGate can inspect manifests and archives before install and block packages with dangerous hooks by policy. | `ua-parser-js` malicious versions used install-time behavior to deploy malware on developer and CI systems. | [CISA: ua-parser-js alert](https://www.cisa.gov/news-events/alerts/2021/10/22/malware-discovered-popular-npm-package-ua-parser-js), [Sonatype: PyPI setup.py cryptomining malware](https://www.sonatype.com/blog/sonatype-catches-new-pypi-cryptomining-malware-via-automated-detection) |
| Build script abuse | Build systems often execute arbitrary code before compilation or packaging completes. SourceGate can flag build scripts, native compilation steps, and commands that download or execute additional payloads. | Malicious crates on crates.io abused `build.rs` behavior, including a case where a build script spawned a bundled PuTTY installer. | [crates.io malware postmortem](https://blog.rust-lang.org/inside-rust/2023/09/01/crates-io-malware-postmortem/), [Rust build script risk profile](https://safeguard.sh/resources/blog/rust-supply-chain-build-scripts-risk) |
| Credential harvesting | A malicious package searches for tokens, cloud credentials, SSH keys, package-manager credentials, browser secrets, or wallet keys. SourceGate can statically flag references to known credential paths, token names, and secret-harvesting APIs. | The malicious `flatmap-stream` package in the `event-stream` dependency chain targeted cryptocurrency wallet data. | [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident), [Microsoft DevOps: blocking event-stream and flatmap-stream](https://devblogs.microsoft.com/devops/blocking-malicious-versions-of-event-stream-and-flatmap-stream-packages/) |
| Environment variable exfiltration | A package reads environment variables and sends them to an attacker-controlled endpoint, often targeting CI secrets and cloud tokens. SourceGate can alert on `process.env`, `os.environ`, bulk environment enumeration, webhooks, and outbound network code. | The fake npm package `tanstack` targeted environment variables while impersonating the TanStack ecosystem. | [Socket: TanStack brandsquat compromise](https://socket.dev/blog/tanstack-brandsquat-compromise), [Practical Automated Detection of Malicious npm Packages](https://arxiv.org/abs/2202.13953) |
| Network beaconing | Malicious install-time code contacts an external host to identify the victim, retrieve commands, or report successful execution. SourceGate can flag hard-coded IPs, suspicious domains, DNS lookups, webhooks, and network APIs inside package archives. | Dependency-confusion proof-of-concept packages commonly reported host and environment information back to the researcher-controlled server. | [Ars Technica: dependency confusion](https://arstechnica.com/information-technology/2021/02/supply-chain-attack-that-fooled-apple-and-microsoft-is-attracting-copycats/), [Snyk: malicious npm packages and dependency confusion](https://snyk.io/blog/snyk-200-malicious-npm-packages-cobalt-strike-dependency-confusion-attacks/) |
| Remote payload download | A package downloads a second-stage payload during install or build, reducing what is visible in the package archive. SourceGate can flag download-and-execute patterns such as `curl | sh`, PowerShell downloads, dynamic imports, and executable writes. | Malicious PyPI typosquatting packages reported by Sonatype used `setup.py` to pull shell scripts and cryptominers during installation. | [Sonatype PyPI cryptomining malware](https://www.sonatype.com/blog/sonatype-catches-new-pypi-cryptomining-malware-via-automated-detection), [Security Affairs: PyPI typosquatting cryptominer](https://securityaffairs.com/119459/cyber-crime/pypi-malicious-packages.html) |
| Obfuscated code | Attackers hide intent with minification, encoding, encrypted strings, packed payloads, or indirect execution. SourceGate can score unusual entropy, encoded blobs, suspicious eval usage, and hidden command construction. | `flatmap-stream` hid malicious logic in the dependency chain used by `event-stream`, and the payload required analysis before its wallet-targeting behavior was clear. | [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident), [Snyk: flatmap-stream malware](https://security.snyk.io/vuln/SNYK-JS-FLATMAPSTREAM-72637) |
| Embedded binaries | Packages can include executables, installers, shared libraries, or platform-specific binary payloads that are difficult to review as source. SourceGate can flag unexpected binaries, executable permissions, suspicious extensions, and binary size anomalies. | The `ua-parser-js` compromise downloaded and ran platform-specific malware, including Windows and Linux payloads. | [CERT-EU: ua-parser-js advisory](https://cert.europa.eu/publications/security-advisories/2021-057/), [Rapid7: ua-parser-js hijack](https://www.rapid7.com/blog/post/2021/10/25/npm-library-ua-parser-js-hijacked-what-you-need-to-know/) |
| Native extension abuse | Native extensions and compilation steps can execute opaque code, invoke compilers, or load binaries during install. SourceGate can alert on native build files, compiled artifacts, and package manifests that trigger native toolchains. | Malicious crates and build scripts in the Rust ecosystem show how native build-time execution can become a supply-chain execution path. | [crates.io malware postmortem](https://blog.rust-lang.org/inside-rust/2023/09/01/crates-io-malware-postmortem/), [Cargo build script security risks](https://safeguard.sh/resources/blog/cargo-build-script-security) |
| Suspicious file writes | Malicious packages may alter shell startup files, SSH configuration, package-manager credentials, startup locations, or project files. SourceGate can flag code that writes to sensitive paths such as `.bashrc`, `.profile`, `.ssh`, `.npmrc`, or `.pypirc`. | Sonatype reported malicious PyPI packages such as `aptx` that tampered with SSH configuration and installed trojan behavior. | [InfoQ: malicious PyPI package tampers with SSH config](https://www.infoq.com/news/2023/02/malicious-pypi-rat-mutants/), [Sonatype malware research](https://www.sonatype.com/blog/another-day-of-malware-malicious-botaa3-pypi-package?hs_amp=true) |
| Package metadata anomaly | Metadata changes can expose risk signals such as brand-new packages, sudden maintainer changes, unusual publish timing, or version jumps. SourceGate can score package age, release cadence, ownership changes, and package popularity before allowing install. | Dependency confusion and typosquatting attacks often rely on new packages with little history, while maintainer compromise creates unexpected new releases on trusted packages. | [Ars Technica: dependency confusion](https://arstechnica.com/information-technology/2021/02/supply-chain-attack-that-fooled-apple-and-microsoft-is-attracting-copycats/), [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident) |
| Dependency tree expansion | A new package version can add unexpected transitive dependencies that contain the actual payload. SourceGate can compare dependency sets across versions and alert when a release introduces suspicious new dependencies. | `event-stream@3.3.6` introduced the malicious `flatmap-stream` dependency into a widely used dependency chain. | [npm: event-stream incident](https://blog.npmjs.org/post/180565383195/details-about-the-event-stream-incident), [Microsoft DevOps: blocking event-stream and flatmap-stream](https://devblogs.microsoft.com/devops/blocking-malicious-versions-of-event-stream-and-flatmap-stream-packages/) |
| Install-time cryptomining | A package installs or runs a cryptominer during package installation, often through lifecycle or build scripts. SourceGate can detect suspicious downloads, miner process names, mining pool domains, executable drops, and install-time script execution. | Malicious `ua-parser-js` versions deployed cryptomining malware, and multiple PyPI typosquatting packages pulled cryptominers through `setup.py`. | [CISA: ua-parser-js alert](https://www.cisa.gov/news-events/alerts/2021/10/22/malware-discovered-popular-npm-package-ua-parser-js), [Sonatype PyPI cryptomining malware](https://www.sonatype.com/blog/sonatype-catches-new-pypi-cryptomining-malware-via-automated-detection) |
| CI-targeted compromise | Attackers design packages to run in build pipelines where secrets, deploy tokens, and cloud credentials are available. SourceGate can enforce stricter CI policy, block lifecycle hooks, and flag access to CI environment variables. | The Rust `CrateDepression` campaign targeted cloud CI environments through a malicious crate and staged malware. | [SentinelOne: CrateDepression](https://www.sentinelone.com/labs/cratedepression-rust-supply-chain-attack-infects-cloud-ci-pipelines-with-go-malware/), [RH-ISAC: CrateDepression technical details](https://rhisac.org/threat-intelligence/cratedepression-rust-supply-chain-attack/) |
| Registry impersonation | A malicious or misconfigured registry endpoint can serve unexpected packages, altered metadata, or packages from the wrong trust domain. SourceGate can validate configured registries, enforce allowed registry hosts, and block public fallback for private scopes. | Dependency-confusion attacks exploit resolution across public and private package sources, making registry-origin policy a core control. | [Ars Technica: dependency confusion](https://arstechnica.com/information-technology/2021/02/supply-chain-attack-that-fooled-apple-and-microsoft-is-attracting-copycats/), [Snyk: dependency confusion packages](https://snyk.io/blog/snyk-200-malicious-npm-packages-cobalt-strike-dependency-confusion-attacks/) |
| Provenance or signature failure | A package lacks expected provenance, attestation, or signature data, or the published artifact does not match trusted source expectations. SourceGate can warn or block when policy requires signed or provenance-backed releases. | The `ua-parser-js` incident shows the risk of trusting a registry artifact solely because it was published by an authenticated maintainer account. | [CISA: ua-parser-js alert](https://www.cisa.gov/news-events/alerts/2021/10/22/malware-discovered-popular-npm-package-ua-parser-js), [CNCF TAG Security: ua-parser-js compromise](https://tag-security.cncf.io/community/catalog/compromises/2021/ua-parser-js/) |
